# Contributing to StubDeck

Thanks for your interest in StubDeck.

Bug reports, feature requests, documentation improvements, and pull requests are welcome.

## Before opening an issue

Please check whether a similar issue already exists.

## Bug reports

Include:

- StubDeck version
- WireMock version
- Java version
- operating system
- deployment type
- steps to reproduce
- expected behavior
- actual behavior
- relevant logs

## Feature requests

Please describe the problem first, then the proposed solution.

If possible, explain the workflow you are trying to improve rather than only the UI change you want.

## Pull requests

Please create or reference an issue before starting a significant change.

Keep pull requests focused on one problem and include tests where appropriate.
