# StubDeck 0.1.0 - Initial public release

This is the first public release of StubDeck.

## Highlights

- Browse and search WireMock mappings
- Filter by HTTP method and URL
- Inspect potentially conflicting mappings
- Manage priorities
- Edit mappings through a form or Raw JSON
- Track CREATE, UPDATE, and DELETE operations
- Prevent concurrent editing of the same mapping
- Control persisted and pending mapping state

## Current limitations

- StubDeck must currently run as a single replica.
- One WireMock instance is managed at a time.
- Multi-instance management is planned.
